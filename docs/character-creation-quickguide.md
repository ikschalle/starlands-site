2. paste the template listed in the full guide into your new file and fill it out

# IMAGES
1. have two images named `portrait.png` (the full image) & `thumb.png` (a cropped square image)
1. create a folder with the name `firstname-lastname` (same as the `.md` file you just made) in https://github.com/stardoods/starlands/tree/main/assets/img/characters
2. place the two images inside
